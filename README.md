# revinel-js

The source of the [`revinel`](https://www.npmjs.com/package/revinel) npm package: the official JavaScript SDK for [Revinel](https://revinel.com), the self-serve ad platform that lets publishers sell ad space directly to advertisers as monthly subscriptions.

**This repository is a read-only mirror.** The package is developed in Revinel's private monorepo, and every commit here is a one-way sync from it. Edits made here are overwritten by the next sync. Found a bug or have a request? Open an issue. Accepted fixes are made in the monorepo and land here with the next release, so a pull request may be closed in favor of the same change made there.

- Package documentation: [`packages/revinel`](packages/revinel)
- Guides and API reference: [revinel.com/docs](https://revinel.com/docs)

## Releases

Each version is published to npm from this repository's GitHub Actions with [npm trusted publishing](https://docs.npmjs.com/trusted-publishers), so every release carries a [provenance attestation](https://docs.npmjs.com/generating-provenance-statements) that links it to the commit and the workflow run that built it.
